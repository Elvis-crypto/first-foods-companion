# First foods

An original companion for the first year of solid food, in English and Hungarian. The dish ideas were inspired by *Anya, kérek még!* (Ambrus Éva, BOOOK Kiadó). The words, recipes, and photographs here were written for this site. The book is not reproduced.

This is general information, not personal medical advice.

## What is here

- Guides in `content/topics/`. Each topic has a title, a byline, findings that link to the matching section, and references with real URLs.
- Recipes in `content/recipes/`. Each record has ingredients, a minimum age in months, a short scrutiny note, and the version to cook.
- A static site generated by `build.py` into `dist/`. English lives at `/`. Hungarian lives at `/hu/`.
- On Vercel, the first visit follows the visitor's country (`x-vercel-ip-country`). Hungary opens the Hungarian pages. Everywhere else opens English. The language menu stores a `lang` cookie that overrides the country on later visits. The cookie is set only when someone uses the menu.
- A night theme is in the navigation. The choice is kept in the browser. Until then, the page follows the system colour scheme.

## Build

```bash
python build.py
```

The script uses only the Python standard library. Open `dist/` with any static file server. Vercel runs the same command and publishes `dist/`.

## Editorial rules baked into the recipes

No added salt or sugar under 12 months. No honey in any recipe. Allergens are introduced around 6 months in a safe texture, except where a clinician should go first. Liver is a small weekly portion. Fish is boneless. The recipe page says whether the underlying idea was sound, adjusted, or replaced.
